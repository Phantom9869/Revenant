Importing requests-html fails with LXML 5.2.0 because the `lxml.html.clean` module is no longer bundled, as it has become a separate project named `lxml_html_clean` [#569]. This results in an `ImportError: lxml.html.clean module is now a separate project lxml_html_clean.` [#576]. One user noted that adding `lxml_html_clean` as an explicit dependency in `setup.py` resolves the import error until a change is made to the project [#569].
