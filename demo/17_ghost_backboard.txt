Importing requests_html fails with lxml 5.2 because the lxml.html.clean module is no longer bundled; it has been moved to a separate project called lxml_html_clean [#569] [#576]. The code attempts to import Cleaner from lxml.html.clean, which raises an ImportError [#569] [#576]. A comment on issue #569 explains that adding lxml_html_clean as an explicit dependency in setup.py fixes the import error [#569].
